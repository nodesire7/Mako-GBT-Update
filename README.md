# Mako GBT 公开更新源

原版 Mako 4.0 用户请下载一次性迁移程序，放在游戏目录的 `Mako Launcher.exe` 旁运行。迁移程序会备份原启动器并打开 GBT 启动器。在主页点「同步更新」，选择「发布包更新」，等待本机生成完成即可进入游戏。 [4.2.19 下载和迁移说明](https://github.com/nodesire7/Mako-GBT-Update/releases/tag/gbt-4.2.19)

已有 GBT 更新功能的用户，可以直接在主页点「同步更新」。启动器使用公开 feed 核对更新版本、下载地址、大小和 SHA-256。 [公开 feed](https://github.com/nodesire7/Mako-GBT-Update/releases/latest/download/feed.json) · [全部版本](https://github.com/nodesire7/Mako-GBT-Update/releases)

4.2.19 的更新包附带启动器、渲染器和便携编译工具。升级时从原安装目录的 `romfs` 和 `.hookshot_exefs` 生成游戏程序、着色器清单、道具轮与界面资源。备份位于 `user/update-backups`，生成日志位于 `logs`。
